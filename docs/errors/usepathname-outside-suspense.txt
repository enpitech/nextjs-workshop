# usePathname() in a Client Component (the nav in the root layout), on a dynamic route, with no <Suspense> around it
# Captured 2026-09-16 with Next 16.3.5, `next build`. Fix: wrap <Nav /> in <Suspense> in app/layout.tsx.

Error: Route "/talks/[id]": Next.js encountered URL data `usePathname()` in a Client Component outside of `<Suspense>`.

This blocks prerendering because the value is only available at runtime.

Ways to fix this:
  - [stream] Wrap the component in `<Suspense fallback={...}>` so the hook value streams in after prerendering
  - [block] Set `export const instant = false` to allow a blocking route

Learn more: https://nextjs.org/docs/messages/blocking-prerender-client-hook
